Cara membuat token
  1. Buka GitHub → Fine-grained token baru.
  2. Repository access: Only select repositories → pilih repo website ini.
  3. Permissions → Contents: Read and write.
  4. Klik Generate token, salin, lalu tempel di atas.

Token hanya disimpan di browser ini, tidak pernah ikut ke website. Jangan bagikan token ke orang lain.
